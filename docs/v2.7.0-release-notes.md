# v2.7.0 九九乘法口诀背诵

## 版本摘要

v2.7.0 新增九九乘法口诀背诵模块。首页保持单一"九九乘法"入口，统一设置页通过"闯关"和"背诵"两个 Tab 分流。背诵以语音领读、孩子跟背和手动确认为主，与闯关的看题作答、即时反馈形成互补，帮助孩子逐步掌握完整九九乘法口诀表。

## 主要变化

- 新增传统九九乘法口诀的 45 句标准口诀，按"一一得一"至"九九八十一"的传统九组顺序组织。
- 支持顺序背和自定义背两种方式，随时切换并共享同一轮 45 句完成进度；顺序背自动定位最早未完成句。
- 自定义背可在 9×9 乘法表中选择任意未完成格；点击 9×1 等反向算式时保留显示方向，但仍朗读标准口诀"一九得九"。
- 每背完一句，口诀表完成一格，乘法表同步展开对应的交换律格；平方口诀只展开一个对角格。
- 45 句全部背完后，口诀表 45 格、9 个分组标题和乘法表 81 格全部展开。
- 进入当前句时自动中文领读一次，并支持"再听一遍"和"停止领读"；语音不可用时自动降级为手动确认。
- 背诵会话独立持久化到 localStorage，刷新后可恢复进度；提供重置确认，清空后从第一句重新开始。
- 乘法表和口诀表始终同页同步显示：宽屏左右并排，窄屏上下排列。

## 体验与质量

- 背诵采用独立路由、状态机、存储和双表组件，原九九乘法闯关矩阵和计算训练数据保持不变。
- 支持键盘完成模式切换、自定义选择、确认和重置取消；自定义背保持单一 Tab 停靠点并支持方向键跳过已完成格。
- 支持减少动态效果偏好，取消当前句进入、新格展开和完成柔光动画，功能保持完整。
- 未背乘积不进入可见文本、DOM 属性或辅助名称，防止答案通过界面泄露。
- 覆盖 `768×1024`、`1024×768`、`1440×900`、`1920×1080` 四档视口。
- 37 个 Vitest 测试文件、394 项测试和 13 个 Playwright spec、82 项 Chromium E2E 全部通过。

## 已知限制

- 口诀背诵只保存当前一轮会话，不保存长期历史成绩，不接入现有计算训练记录。
- 语音领读依赖浏览器 `speechSynthesis`，部分浏览器或系统可能不支持中文语音。
- 手机小屏暂不支持；宽度低于 `768px` 时继续显示设备提示。
