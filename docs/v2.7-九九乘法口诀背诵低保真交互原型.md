# v2.7 九九乘法口诀背诵低保真交互原型

## 1. 原型目标

本原型用于执行 v2.7 步骤 3“低保真交互原型”，验证统一九九乘法设置页、顺序背、自定义背、双表同步、交换律展开、语音、恢复、重置和整表完成流程。

原型采用灰度线框，只表达结构、状态、尺寸和操作。配色、插画、品牌图形、阴影和庆祝效果等最终视觉不在本步骤确定。

当前状态：**步骤3已完成并通过用户体验确认，下一步进入UI视觉设计**。

## 2. 原型入口

原型文件：[prototypes/v2.7-recitation-low-fi.html](./prototypes/v2.7-recitation-low-fi.html)

从项目根目录启动静态服务：

```bash
python3 -m http.server 4173
```

浏览器打开：

```text
http://127.0.0.1:4173/docs/prototypes/v2.7-recitation-low-fi.html
```

原型不依赖 React、Ant Design 或生产路由。它只使用演示键 `v2.7-recitation-low-fi-session` 验证刷新恢复，不读取或写入 `practice-records` 及生产乘法数据。

## 3. 原型范围

### 3.1 正常体验模式

- 统一设置页默认打开闯关 Tab，可切换到背诵 Tab；
- 背诵 Tab 支持首次开始、继续、查看 45/45 完成结果和重新开始；
- 顺序背从传统顺序中最早未完成口诀继续；
- 当前句自动领读，可停止领读、重播并由孩子手动确认；
- 自定义背可在 9×9 乘法表选择任意未完成格；
- 点击 `9×1` 时显示 `9×1=9`，同时使用标准口诀“一九得九”；
- 顺序背和自定义背随时切换并共享完成进度；
- 普通口诀完成后展开两个对称格，平方口诀展开一个对角格；
- 刷新恢复完成集合和最近模式，不恢复语音播放位置；
- 重置需要确认，确认后立即回到 `0/45` 和“一一得一”；
- 第 45 句完成后展示口诀表 45 格和乘法表 81 格全部完成。

### 3.2 评审工具条

页面顶部虚线区域是原型专用评审工具，不属于产品界面。它可以快速切换：

- `768 / 1024 / 1440` 三种预览宽度；
- 闯关设置、背诵设置、顺序背、自定义背、12/45、44/45、45/45；
- 正在领读、语音不可用、存储失败、损坏数据回退和重置确认；
- `1024` 的左右并排、上下排列候选；
- 正常动态与减少动态效果；
- 清除原型专用演示存储。

工具条可以折叠；它不属于产品界面，也不计入 `1440×900` 产品首屏高度。

评审状态用于快速查看边界，不要求评审者手动完成 45 句。正常体验模式仍可从设置开始逐句走通。

## 4. 线框与响应式结论

### 4.1 统一设置页

- 首页与顶部导航继续只有一个“九九乘法”入口；
- 设置页用“闯关 / 背诵”两个 Tab 分流，默认闯关；
- 闯关面板保留 v2.6 的三档难度和四种题量；
- 背诵面板根据会话显示开始、继续、完成结果和重新开始；
- 选中状态使用边框、文字和语义属性，不只依赖颜色。

### 4.2 背诵页面

页面顶部采用一个吸顶的单行控制栏：

1. 从左到右依次放返回、顺序/自定义模式、当前口诀、语音操作、确认、进度和重新开始；
2. 取消“口诀背诵”页面标题，以“算式 · 标准口诀”作为视觉主体；
3. 领读状态融入按钮文案和禁用状态，语音不可用时显示短按钮文案；
4. 进度条作为控制栏底部细线，不独立占行；
5. 完成态在同一行显示“45句全部背完 · 两张表已展开”，不插入大型完成卡片。

两张表始终在同一页面并同步更新，不使用控件隐藏其中一张。

两张表删除独立标题和说明段落，改为边框内小标签：“乘法表”同行提示交换律展开，“45句口诀表”同行显示“未背 / 当前 / 已背”。语义标题通过 `aria-labelledby` 保留。

口诀表顶部增加中文“一”至“九”列头，不计入45句进度。这样左右网格均为10行：乘法表表头对应口诀表中文列头，乘数1–9分别对应第一组至第九组，所有横向分隔线逐行对齐。

每个中文列头同时反馈对应口诀组是否全部背完。完成整组后，标题文字保持不变，只切换为与右侧已背口诀格相同的底色和字重；部分完成不改变标题。左侧乘法格继续使用勾选，右侧口诀格和分组标题统一使用底色，两套反馈不混用。标题状态完全由45句完成集合派生，不增加会话字段。

### 4.3 三种支持宽度

| 视口 | 双表布局 | 乘法表宽度 | 口诀表宽度 | 横向滚动 |
|---|---|---:|---:|---|
| `768×1024` | 上下排列 | `704px` | `704px` | 无 |
| `1024×768` | 上下排列 | `624px` | `948px` | 无 |
| `1440×900` | 左右并排、等高 | 约 `619px` | 约 `731px` | 无 |

`1024×768` 的并排候选测得乘法表约 `404px`，单格约 `40px`，口诀区域约 `500px` 且需要将文字压缩到 `9px`。这不满足儿童触控和口诀可读性要求，因此正式低保真结论选择上下排列。原型评审工具仍保留两种候选，便于复核差异。

单行与双表等高优化后，`1440×900` 产品壳总高约 `760px`；控制内容行高 `48px`，含 `3px` 进度线和边框的控制栏总高约 `53px`。右侧口诀表维持 `573px` 面板和 `532px` 网格高度，左侧使用相同的显式高度，不依赖内容拉伸，10 行均分为约 `52–53px`。不计评审工具条时，导航、控制栏和两张完整表均位于首屏内。

实测左右10行的每一条上、下边界差值均为 `0px`。口诀表包含9个表头、45个有效口诀格和36个空白占位格；表头使用 `columnheader` 语义，不进入完成统计。

Firefox会比Chrome更严格地保留Grid子项的最小内容尺寸，单纯设置父网格高度仍可能被口诀格反向撑开。原型因此同时锁定1440面板的 `height/min-height/max-height`、网格的固定伸缩基准与最大高度，并将两侧网格直接子项设为 `min-block-size: 0`；网格使用内部裁切防止内容改变轨道尺寸。Chrome自动回归显示两侧仍为573px/532px且无内部溢出，Firefox需在用户环境刷新后复核。

等高规则只用于 1440 左右并排布局。1024 和 768 上下布局继续使用正方形乘法格，实测约为 `62px` 和 `72px`，不为追求等高牺牲触控尺寸。

## 5. 自动化自检

### 5.1 内容与映射

- 口诀表包含恰好 45 个有效口诀格；
- 乘法表包含恰好 81 个乘法格；
- 未完成乘法格可见文本不包含乘积；
- `1×9` 与 `9×1` 映射到同一规范口诀“一九得九”；
- 完成“一一得一”只展开 `1×1`；
- 完成“一二得二”后同时展开 `1×2` 与 `2×1`；
- 45/45 评审状态包含 45 个完成口诀格和 81 个完成乘法格。

### 5.2 交互与状态

- 初始打开原型显示统一设置页的闯关 Tab；
- 从背诵 Tab 开始后进入 `0/45` 和“一一得一”；
- 领读结束或主动停止后才开放“我背完了”；
- 快速双击确认只完成一句；
- 自定义点击 `9×1` 显示 `9×1=9` 并使用“一九得九”；
- 自定义完成后 `1×9` 与 `9×1` 同时展开、禁用；
- 自定义切回顺序背后定位最早未完成口诀；
- 9×9 自定义表只有一个 Tab 停靠点，方向键移动后更新停靠点；
- 刷新后恢复背诵页、完成数量和当前顺序句；
- 重置取消保持进度，确认后完成格归零并回到第一句；
- 语音不可用时确认操作仍可用；
- 存储失败时显示非阻断恢复风险提示；
- 减少动态效果时流程和状态保持完整。

### 5.3 视口与稳定性

- 三个真实 Chromium 目标视口的 `scrollWidth` 均等于视口宽度；
- `768`、`1024` 的上下布局与 `1440` 的并排布局符合预期；
- 单行控制栏在长页面滚动时保持可见；
- 顺序、自定义、混合进度、44/45、45/45、领读、语音不可用和存储失败均保持 `48px` 单行；
- `1440×900` 两块面板均为约 `573px`，上下边缘误差为 `0px`，产品区总高约 `760px`；
- 左右10行逐行边界误差为 `0px`，中文表头顺序为“一、二、三、四、五、六、七、八、九”；
- 分组标题只在组内 `n` 句全部完成后切换底色；44/45时前八组完成、缺少“九九八十一”的第九组保持未完成，45/45时九个标题全部完成；
- Chrome各关键状态下计算高度固定为573px/532px且无内部溢出；Firefox最小内容撑高问题增加专用约束后已通过用户环境复核；
- `1024×768` 与 `768×1024` 的乘法格最小宽度分别约 `62px` 和 `72px`；
- 完成态不存在大型完成面板，仍恰好展开 45 个口诀格和 81 个乘法格；
- 页面没有 JavaScript error、console warning 或未处理异常；
- 原型脚本通过语法检查。

## 7. 用户体验确认清单

请优先体验以下路径：

1. 首次进入确认一个九九乘法入口和闯关/背诵 Tab 是否清楚；
2. 折叠评审工具条并切到 `1440`，确认导航、单行控制栏和两张完整表可以一眼看全；
3. 在 `1024` 比较并排和上下排列，确认上下排列更清晰；
4. 从顺序背完成前两句，判断“领读—跟背—确认—下一句”节奏；
5. 切到自定义背，分别选择 `1×9` 与 `9×1`，观察算式方向和标准口诀；
6. 完成一句后确认口诀格与交换律乘法格同步展开；
7. 尝试选择已完成格，确认禁用状态容易理解；
8. 在待确认时切换两种背法，确认未完成句不会误计且完成进度保留；
9. 刷新页面后确认当前轮可以继续；
10. 取消一次重置，再确认重置，判断是否足以防误触；
11. 查看语音不可用和减少动态效果状态；
12. 切换到 45/45，确认完成信息放在顶部后明确且不过度庆祝，表格不会被向下推移。
13. 在Firefox刷新原型并选择1440，确认左右面板、网格和10条横向行线与Chrome一致。
14. 分别查看部分完成、整组完成、44/45和45/45，确认标题仅在整组完成后改变底色且不显示勾选。
