# v2.8.0：九九神枪手实施与验收

## 产品规则

九九乘法闯关新增第四档最高难度「九九神枪手」。固定1–9行列和81格，根据乘积寻找全部因数坐标。每局随机排列36个不同乘积，固定36轮、81发子弹，每轮1–4发。显示目标乘积、正确格数、剩余子弹、累计命中和轮次。

每点击一个可射击格消耗一发，立即判定命中或打空；本轮不能重复射击、撤销或补弹。命中格累计展开且禁射；打空与漏射标记只在本轮显示。子弹用完揭晓全部正确算式，显示评价，手动进入下一轮。揭晓不计命中，只有81发全中才能打开完整乘法表。

## 连击、动画与声音

连续命中跨轮累计，无时间窗口，打空归零。第二次连续命中开始展示连击数字，每次命中弹出约300毫秒；5、10、20、40、81连击增加文字和光圈反馈。再次建立连击后可重新获得对应里程碑。命中格亮起光圈，打空格叉号与局部抖动，连击中断短暂提示；反馈不遮挡棋盘、不阻塞射击，不增加分数或子弹。

复用Web Audio与本机音效开关偏好。命中音随连击分为有限音阶并封顶；打空采用柔和低音。完美轮末合并最后一次命中音为短和弦，不叠加两次播放。快速射击替换旧音，不排队。静音立即停止，离页释放资源，音频不可用时静默降级。减少动态效果时去除缩放、抖动与光圈动画，保留静态状态和文字。

## 流程与技术实现

- 统一设置页新增第四档；选中后隐藏题量选项，提示固定36轮、81发，切回传统难度保留原题量。
- 复用会话、结果路由；入口组件按难度分派，传统答题逻辑保持独立。神枪手领域模型、页面及样式位于 `src/features/multiplication/sharpshooter/`。
- 纯状态转换原子计算射击、扣弹、连击及全中轮次。页面用同步状态引用接收快速输入，声音不在React状态更新函数或重复执行的渲染副作用内播放。
- 独立路由数据为 `{ settings: { difficulty: 'sharpshooter', questionCount: 36 }, rounds: number[36] }`；结果增加完整射击记录、作答用时及评价。结果校验重放81次射击，拒绝重复射击、伪造命中或分数。
- 开局先说明规则，主动开始后计时；揭晓时暂停，下一轮续计。刷新和非法会话返回设置，不保存长期成绩，不改动背诵存储。
- 结果展示命中数、命中率、全中轮数、最高连击、作答用时和星级；重开随机新局。
- 得分为命中数/81的百分制四舍五入值；≥90三星、≥80二星，否则一星。时间和连击不影响评分。
- 鼠标、触控和方向键移动焦点，Enter/空格射击；已射击格保留焦点能力但不能再射，轮末焦点进入下一轮按钮。无障碍即时播报命中与剩余弹数。
- 768/1024上下布局，1440/1920左右布局；不适配低于768的小屏。
