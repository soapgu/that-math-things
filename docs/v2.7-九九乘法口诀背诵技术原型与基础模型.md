# v2.7 九九乘法口诀背诵技术原型与基础模型

## 1. 目标与结果

本文件记录v2.7步骤5“技术原型与基础模型”的实现与验收结果。当前状态：**已完成**。

本步骤建立了可供步骤6直接复用的口诀领域模型、Schema v1会话、独立存储、中文领读控制器和两张React表格，并通过独立技术原型验证完整接线。本步骤没有注册生产路由、改造正式设置页或读写既有业务数据。

技术原型：[`prototypes/v2.7-recitation-tech.html`](./prototypes/v2.7-recitation-tech.html)

## 2. 最终复用边界

- 乘法坐标范围、单元格键和乘积计算提取到共享坐标模块；原闯关模型继续从原入口导出`getCellKey`，调用方无需迁移。
- 原`MultiplicationMatrix`继续只服务闯关，不加入背诵条件分支。
- 背诵新增`RecitationMultiplicationTable`和`PhraseTable`，只消费安全视图模型。
- 生产背诵页在步骤6使用独立`/multiplication/recitation`路由和状态机，并继续位于现有`AppLayout`中。
- `/multiplication`在步骤6改为共享设置容器；闯关设置作为原行为不变的子视图，背诵使用独立子视图。

该边界复用稳定的数学能力与页面外壳，同时隔离闯关的难度、抽题、计时、作答反馈、评分和星级。

## 3. 基础模型

领域模块位于`src/features/multiplication/recitation/`，公开能力包括：

| 能力 | 关键接口 | 结果 |
|---|---|---|
| 45句口诀 | `RECITATION_PHRASES`、`getPhraseById` | 九组1–9句，传统顺序，总计45句 |
| 交换律映射 | `createPhraseId`、`coordinateToPhrase` | 81个有序坐标映射到45个规范ID，保留点击方向 |
| 双格展开 | `getExpandedCoordinates` | 36句展开两个对称格，9句平方口诀展开一个格 |
| 进度派生 | `findFirstIncompletePhrase`、`isPhraseGroupComplete` | 顺序定位与九个分组标题无需额外存储 |
| 安全视图 | `buildRecitationMatrixView`、`buildRecitationTableView` | 未背乘法格不携带乘积；表格统计固定为81、45、36、9 |
| 会话转换 | `selectRecitationCoordinate`、`switchRecitationMode`、`completeCurrentPhrase` | 两种方式共享进度，选择方向保留，确认幂等 |

中文口诀使用一至九作为因数，小于10的乘积使用“得”，10及以上省略“得”。例如`9×1`显示方向仍为`9×1=9`，规范ID和领读均为`1×9 / 一九得九`。

## 4. 会话、存储与语音

会话使用独立Schema v1和存储键`multiplication-recitation-session-v1`。读取时校验版本、模式、规范ID、坐标、当前句、完成集合和时间；任何无法识别的组合整体回退为空会话。完成集合去重并恢复为传统顺序。

存储写入失败返回`{ ok: false, reason }`，当前内存会话仍可继续。模块不读取或写入`practice-records`、`multiplication-sound-enabled`和闯关路由状态。

领读控制器固定使用`zh-CN`和`0.82`语速。每次播放先取消旧语音，并通过播放序号隔离取消后延迟到达的`onend/onerror`；不可用、异常和卸载均安全降级到手动确认流程。

## 5. React技术原型

原型直接导入正式模型、存储、语音与双表组件，不复制算法，覆盖顺序、自定义、模式切换、共享进度、`9×1`方向显示、四种进度状态、恢复与异常，以及四档响应式。

- 新增5个测试文件、33项测试；全量36个测试文件、353项测试全部通过。
- 原闯关模型、矩阵、设置和24项完整流程测试全部通过。

- 评审修复复核通过：顺序句自动领读，非平方口诀仅规范方向为当前，快速双击只推进一句，自定义按钮保持完整Grid语义和单Tab停靠点，方向键可跳过已完成格并通过原生按钮行为完成键盘选择；重复选择当前坐标不打断领读，切换交换律坐标会保留方向并重新领读，StrictMode下损坏会话提示保持可见；评审宽度可独立切换布局。

双表继续使用步骤3已由用户在Firefox确认的显式Grid策略：宽屏锁定面板与网格高度，10行使用`minmax(0, 1fr)`，行和单元格允许收缩并限制溢出。步骤6接入生产页面后仍需按最终验收清单复核Firefox字体、焦点和行线。
