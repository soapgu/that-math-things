# v2.7 九九乘法口诀背诵实施计划

## 1. 版本目标

### 1.1 产品目标

在现有“九九乘法”模块中增加专注于开口背诵和重复记忆的口诀背诵模式。首页继续只有一个“九九乘法”入口，进入统一设置页后，通过“闯关”和“背诵”两个 Tab 选择学习方式。

背诵模式围绕传统九组共 45 句口诀展开，所有背诵方式都以完成整张口诀表为目标：

- **顺序背**：按照传统第一组至第九组自动定位下一句；
- **自定义背**：孩子在 9×9 乘法表中点击任意尚未完成的算式；
- 两种方式随时切换，共享同一轮 45 句完成进度；
- 每句由系统中文领读，孩子跟背后手动确认完成；
- 完成口诀时同步展开对应的交换律乘法格，45 句完成后展开全部 81 格。

### 1.2 非目标

v2.7 不包含以下内容：

- 不增加首页第四个入口；
- 不增加指定口诀组或部分范围训练，目标始终是完整 45 句；
- 不提供独立的正向、反向设置，也不提供从“九九八十一”倒序背诵；
- 不使用麦克风，不做语音识别或背诵准确性判断；
- 不加入计时、评分、星级、历史成绩、错题重练或能力评价；
- 不写入加减法 `practice-records`，不修改 v2.6 闯关数据；
- 不在本版本规划 v2.8 及之后的功能。

## 2. 统一入口与页面流程

### 2.1 首页与设置页

- 首页保持现有一个“九九乘法”卡片，继续进入 `/multiplication`。
- `/multiplication` 改为统一设置容器，包含“闯关”和“背诵”两个 Tab。
- “闯关”Tab 完整保留 v2.6 的三档难度、四种题量和开始闯关行为。
- “背诵”Tab 展示功能说明、当前进度和开始、继续、重新开始操作。
- 默认打开“闯关”Tab，保证旧入口和已有测试兼容。
- Tab 使用查询参数表达：
  - `/multiplication?mode=challenge`
  - `/multiplication?mode=recitation`
- 缺少或无法识别 `mode` 时回退到 `challenge`。
- 切换 Tab 使用替换式导航，避免浏览器返回在两个设置面板间反复跳转。
- 从背诵流程返回设置页时进入背诵 Tab；从闯关流程返回时进入闯关 Tab。

### 2.2 背诵入口

背诵 Tab 根据会话状态显示：

- 无会话时显示“开始背诵”，创建一轮完整 45 句会话；
- 有未完成会话时显示“继续背诵”和“已背 x/45 句”；
- 已完成会话时显示 45/45 完成状态和“查看完成结果”；
- “重新开始”需要二次确认，确认后清空本轮进度并从第一句开始；
- 背诵页面默认使用顺序背，页面内可以随时切换顺序背和自定义背。

### 2.3 背诵页面

背诵页面包含同一份进度驱动的两个核心区域：

1. **9×9 乘法表**：呈现 81 个有序乘法坐标，用于展示交换律展开结果，并在自定义背时选择下一句；
2. **45 句口诀表**：使用传统下三角结构呈现未背、当前和已背状态。

两个区域始终位于同一页面并使用同一份完成状态：`1440×900` 左右并排并以口诀表为基准严格等高，口诀表增加中文“一”至“九”表头，使两侧均为10行并逐行对齐；`768×1024` 和 `1024×768` 上下排列并保留正方形乘法格，不使用切换控件隐藏其中一张表。步骤3已验证1024并排会使乘法格和口诀文字过小，因此定稿为上下排列。背诵页采用吸顶单行控制栏，当前口诀替代页面标题，表格标题收进边框内；`1440×900`不计原型评审工具条时需在首屏完整显示导航、控制栏与两张表。

## 3. 口诀内容与顺序

### 3.1 传统 45 句

- 第 `n` 组包含 `1×n` 至 `n×n`；
- 九组数量分别为 1、2、3、4、5、6、7、8、9 句，总数严格为 45；
- 顺序背按第一组至第九组推进，组内按第一个因数递增；
- 规范口诀 ID 始终使用较小因数在前的方向，例如“一九得九”为 `1×9`；
- 乘积小于 10 时使用“得”，例如“一三得三”；
- 乘积达到 10 后省略“得”，例如“二五一十”“三六十八”。

### 3.2 顺序背

- 自动定位传统顺序中最早一条尚未完成的口诀；
- 进入当前句时自动朗读一次；
- 孩子跟背后点击“我背完了/下一句”手动确认；
- 语音播放结束不能自动完成或推进；
- 从自定义背切回顺序背时，重新查找最早未完成句，不要求重复已完成口诀；
- 第 45 句完成后进入整表完成状态。

### 3.3 自定义背

- 孩子在完整 9×9 乘法表中点击任意未完成单元格；
- 点击方向决定当前算式的显示方向，不改变规范口诀 ID 和朗读文字；
- 点击 `1×9` 时显示 `1×9`，点击 `9×1` 时显示 `9×1`，两者均朗读“一九得九”；
- 自定义选择后进入该句的自动领读和手动确认流程；
- 确认后返回乘法表继续选择，或切换到顺序背；
- 已完成口诀对应的两个交换律格均不可再次选择；
- 平方口诀只有一个对角格。

## 4. 展开、语音与完成规则

### 4.1 口诀表状态

- 45 个口诀格分别具有未背、当前、已背状态；
- 每次手动确认只完成当前一个规范口诀格；
- 当前状态必须具有文字、图标或边框等非颜色提示；
- 已完成口诀在顺序背中自动跳过，在自定义背中不可再次选择。

### 4.2 乘法表展开

- 普通口诀完成后，同时展开两个交换律对称格，例如 `1×9` 和 `9×1`；
- 平方口诀只展开一个对角格，例如 `6×6`；
- 已展开格显示乘积并禁用选择；
- 自定义模式当前选中格具有独立高亮；
- 36 句非平方口诀各展开 2 格，9 句平方口诀各展开 1 格，完成 45 句后恰好展开 81 格；
- 不提前显示未背口诀的乘积，也不在隐藏 DOM 或可访问名称中泄露未展开结果。

### 4.3 语音规则

- 使用浏览器 `speechSynthesis` 与 `SpeechSynthesisUtterance`；
- `lang` 设置为 `zh-CN`，朗读内容使用标准中文口诀；
- 每次进入当前句自动朗读一次，并提供“再听一遍”；
- 切句、切换模式、重置、离开页面和组件卸载时取消旧播报；
- 浏览器不支持语音时隐藏或禁用朗读控制，但手动背诵流程保持完整；
- 语音失败不能改变进度，也不能阻止孩子手动确认。

## 5. 会话模型与数据边界

### 5.1 Schema v1

背诵使用独立本地会话，逻辑结构为：

```text
schemaVersion: 1
orderingMode: sequential | custom
currentPhraseId: 规范口诀 ID | null
selectedCoordinate: { a, b } | null
completedPhraseIds: 规范口诀 ID 数组
updatedAt: ISO 时间
```

### 5.2 会话规则

- 顺序背和自定义背共享同一个 `completedPhraseIds`；
- `1×9` 与 `9×1` 都映射到规范 ID `1×9`；
- 本机只保存当前一轮会话，刷新或离开后可以继续；
- 重置清空当前轮全部进度并回到顺序背第一句；
- 完成 45 句后保留完成画面，直到主动重新开始；
- 读取时去除重复 ID，并校验 ID、坐标、当前句和模式；
- 损坏、越界或版本不兼容的数据回退为安全空会话；
- 使用独立 localStorage key，不读取或写入 `practice-records`；
- 不修改乘法闯关设置、声音偏好或路由会话。

## 6. 复用与技术边界

- 可复用乘法坐标校验、乘积计算、单元格键和既有视觉令牌；
- 浏览器语音应提取为具有播放、取消和不可用降级能力的独立封装，避免复制旧动画组件实现；
- 不复用闯关题目抽取、难度、题量、计时、评分、星级和答题状态机；
- 背诵使用独立领域模型、存储边界、页面路由和交互状态；
- 现有矩阵组件是扩展还是另建，在步骤 4 视觉设计和步骤 5 技术原型中根据可选、当前、已完成和隐藏状态决定；
- v2.6 闯关原有 `/multiplication/session` 与 `/multiplication/result` 行为保持兼容。
