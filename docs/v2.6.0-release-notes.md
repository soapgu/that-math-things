# v2.6.0 九九乘法闯关

## 版本摘要

v2.6.0 新增独立的“九九乘法”学习模块，以 9×9 乘法矩阵为核心，让孩子通过定位、作答、即时反馈和累计开图逐步掌握完整九九乘法表。

## 主要变化

- 新增简单、提升、挑战三档难度，以及 10、20、50、81 四种题量。
- 题目从 81 个有序乘法坐标中无放回生成；81 题模式可完整打开整张九九乘法表。
- 已提交题目永久保留在本局矩阵中，正确与错误状态清晰可辨，并可作为后续题目的推导线索。
- 乘法轴先定位两个乘数，再发射横纵光束；简单显示整行整列提示，提升只显示相邻提示，挑战不显示乘积提示。
- 简单模式使用四选一，提升和挑战在目标格内输入；支持 Enter 提交、即时反馈、交换律对称格和自动/手动切题。
- 结算展示星级、分数、正确题数和活动作答用时，并支持按原设置再来一局。

## 体验与质量

- 支持键盘完成设置与答题，补齐焦点流转、礼貌播报和矩阵 ARIA 行列语义。
- 支持减少动态效果偏好，取消位移、摇动、弹跳和彩屑，同时保留完整流程和计时边界。
- 覆盖 `768×1024`、`1024×768`、`1440×900` 三档视口。
- 30 个 Vitest 文件、315 项测试和 12 个 Playwright spec、73 项 Chromium E2E 全部通过。

## 已知限制

- 九九乘法闯关不保存历史，不写入现有计算训练的 `practice-records`。
- 刷新或确认离开会丢弃当前闯关会话。
- 手机小屏暂不支持；宽度低于 `768px` 时继续显示设备提示。
